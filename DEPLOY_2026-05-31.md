### 2a — Add FRED API key (if not already set)

```bash
grep FRED_API_KEY .env || echo "FRED_API_KEY=your_key_here" >> .env
```

Get a free key at: https://fred.stlouisfed.org/docs/api/api_key.html

> **Without a FRED key**: the system still works fully — scenarios run, analytics compute, macro context fields are `null` (graceful degradation, no crash).

### 2b — Restart the service

```bash
systemctl restart wlthos
# or if running via supervisor / pm2:
# supervisorctl restart wlthos
# Verify it's up:
systemctl status wlthos
curl -s http://localhost:8000/health | python3 -m json.tool
```

On restart, `create_all()` will automatically create the new `macro_observations` table. No manual SQL needed.

## What this unlocks

- **Admin login** — fixed. `POST /api/v1/auth/login` returns a token.
- **Analytics Tier 2+3** — every `POST /analytics/{id}/rerun` now returns scenarios + macro sensitivity + lookthrough in one call.
- **Scenario API** — `GET /scenarios/{portfolio_id}` returns 20 institutional scenarios enriched with live FRED baseline + implied shocked levels.
- **Macro API** — `GET /api/v1/macro/snapshot` exposes the full 12-series FRED snapshot. `POST /api/v1/macro/sync` triggers a manual refresh.
- **Methodology version** — every response carries `methodology_version: wealthos_analytics@3.0` for audit traceability.
