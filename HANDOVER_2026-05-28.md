### P3 — Analytics Engine Upgrades (Citadel/BlackRock level)
Current engines exist but need review/hardening:

**A. Covariance Estimation**
- `robust_stats_engine.py` — check if Ledoit-Wolf (2004) shrinkage is actually implemented
- Should use: `sklearn.covariance.LedoitWolf` or manual Oracle Approximating Shrinkage (OAS)
- Formula: `Σ_LW = (1-α)·S + α·μ·I` where S = sample covariance, μ = trace(S)/p

**B. CVaR (Expected Shortfall)**
- Current: Check if historical simulation is implemented
- Need: Cornish-Fisher expansion for fat tails: `VaR_CF = μ + σ·(z + (z²-1)·γ₁/6 + (z³-3z)·γ₂/24 - (2z³-5z)·γ₁²/36)`
- CVaR = E[loss | loss > VaR]

**C. Factor Decomposition**
- `factor_engine.py` + `risk_models_engine.py` — Barra-style 6-factor model
- Factors: Market (Nifty 50), Size (log MCap), Value (B/P ratio), Momentum (12-1 month), Quality (ROE), Low-Vol
- Output: factor exposure vector β, factor covariance Fᵀ·F, specific risk ε

**D. Scenario Propagation**
- `scenario_engine.py` — verify beta-weighted impact: `ΔP = Σᵢ wᵢ · βᵢ · ΔMacro`
- Add cross-asset correlation matrix in propagation (oil up → INR weak → IT beneficiary)
