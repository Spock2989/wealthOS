## 1. WHAT IS WEALTHOS AI

A B2B portfolio intelligence platform for Indian wealth advisors (RIAs, MFDs, CAs). Advisors upload client CAS PDFs or CSV/Excel holdings, the system runs 10 deterministic analytics modules, and generates AI-powered insights using Claude.

**Core principle:** LLMs NEVER perform financial calculations. All analytics are deterministic, code-driven, reproducible. LLMs only explain, summarize, and narrate.

**Comparable to:** Bloomberg Terminal, Addepar, FactSet — but for Indian wealth management and AI-native.

## 7. KEY ARCHITECTURAL DECISIONS

1. **All analytics are deterministic** — No LLM touches calculations. The 10 analytics modules produce structured JSON. AI only narrates.

2. **Single-file frontend** — App.jsx is one 42KB file with all views. This was done to avoid module/build issues during setup. Can be refactored into components later.

3. **SQLite for now** — Good for 100 clients. Migrate to PostgreSQL when scaling.

4. **Synchronous API calls** — Upload → Parse → Normalize → Analyze all happen in one request. Should be made async with Celery for production.

5. **Sector mapping is keyword-based** — Uses instrument name keywords to classify sectors and market cap. Needs ISIN master data integration for accuracy.

6. **Stress test scenarios are calibrated** — Based on India market 2000-2024 historical data. Each scenario has asset-class-specific shock parameters.

7. **AI Insights make 3 separate Claude calls** — Portfolio Summary, Meeting Prep Notes, Risk Commentary. Takes 15-30 seconds total.

## 12. IMPORTANT TERMINAL TIPS

- Always run backend commands from ~/wealthos/backend with venv activated
- If Terminal hangs, use Cmd+N for new window or Cmd+Q to force quit
- Never run `find /` — it searches the whole disk and freezes
- Use `python3 -c "..."` for writing files — more reliable than `cat > file << EOF`
- Backend auto-reloads on file changes (--reload flag)
- If port is in use, frontend auto-picks next port (5174, 5175, etc.)
